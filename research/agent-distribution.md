# Agent distribution

- Gemini CLI extension: the root manifest and two explicitly invoked slash commands provide research guidance. No hooks, automatic shell actions, or credential requirements. Install from the public Git repository only after reviewing it. Official gallery discovery additionally requires the `gemini-cli-extension` GitHub topic, and actual listing is separately verified. Do not claim gallery indexing from manifest existence.
- MCP bundle: a downloadable read-only catalog, not a remote service. See [bundle source](../mcp_bundle/README.md). Publish only a verified bundle with a digest, then check the official Registry response. No personal machine, secret, or SNS account is used.
- All promotion is opt-in and accurate; no automated installs, engagement, or unsolicited posting. Actual external research PRs are the primary outcome.
